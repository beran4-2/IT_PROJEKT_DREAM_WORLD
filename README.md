# Dream World

**Dream World** je textová adventura napsaná v Javě. Hráč se v ní ponoří do snového světa, kde může prozkoumávat různé lokace, plnit úkoly, komunikovat s postavami a bojovat s nepřáteli.

## O hře
Hra se hraje přes textovou konzoli. Obsahuje správu inventáře, vývoj vlastností postavy, systém úkolů (questů), souboje a komunikaci s různými postavami (NPC). Zásadním prvkem hry jsou také mechaniky spánku a denního snění.

### Hlavní herní prvky:
* **Průzkum světa:** Pohyb po lokacích a odhalování nových míst.
* **Inventář a předměty:** Sbírání, správa a používání předmětů.
* **Úkoly (Questy):** Získávání a plnění úkolů pro posun ve hře.
* **Soubojový systém:** Textové souboje s nepřáteli.
* **Komunikace:** Interakce s NPC prostřednictvím systému dialogů.
* **Spánek a sny:** Herní mechaniky spánku a denního snění.
## Jak hru spustit

### Požadavky
* Nainstalovaná **Java**

### Spuštění
Pro spuštění hry otevři příkazový řádek a složku kde se nachází JAR soubor, např `C:\Users\...\Downloads\DREAM WORLD`. Tuto adresu zkopírujte do příkazového řádku a poté zadejte tento příkaz: `-jar IT_PROJEKT_DREAM_WORLD.jar`



## Ovládání / Dostupné příkazy
Hra se ovládá psaním textových příkazů do konzole. Základní příkazy jsou:

* `jdi dal/zpatky` - Přesun do jiné propojené lokace.
* `inventar zobrazit` - Zobrazení aktuálního stavu inventáře.
* `pouzit pridat/odebrat` - Použití konkrétního předmětu z inventáře.
* `ukoly` - Zobrazení aktivních a splněných úkolů.
* `mluvit` - Zahájení rozhovoru s postavou v aktuální lokaci.
* `vlastnosti` - Výpis vlastností tvé postavy (zdraví, síla atd.).
* `spat` / `daydream` - Uspání postavy / zahájení denního snění.
* `napoveda` - Vypíše seznam všech dostupných příkazů a základní principy hry.
* `konec` - Command který ukončí hru.
